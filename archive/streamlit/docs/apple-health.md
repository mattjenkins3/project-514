This optional import runs on the iPhone and can reach your database while Streamlit sleeps. The beta accepts one total for workout minutes per calendar date and a measured VO₂ max in mL/kg/min on its measurement date. It keeps the two fields separate. A missing measurement stays unknown.

1. In **Profile → Apple Health**, turn on **Allow iPhone Shortcut imports** and copy the private import token. In your Supabase dashboard, copy the project URL and **publishable** API key (starts with `sb_publishable_`). Use the same dedicated project as the app.
2. In Apple **Shortcuts**, create a shortcut. Select the last complete calendar day in your training time zone (the start of yesterday through the start of today). Use **Find Health Samples** for workouts where supported by your iOS version, get their durations in minutes and sum them. Choose one source when a watch and another app recorded the same workout. Format yesterday’s date as `yyyy-MM-dd`.
3. Add **Get Contents of URL**. Use your project URL followed by `/rest/v1/rpc/project514_import`. Choose **POST**, set the header `apikey` to the publishable key, and select a JSON request body. Add `token` (Text, the private import token), `sample_day` (Text, the formatted date) and `workout_minutes` (Number, rounded total). Submit zero only when you know no workout occurred. If Health access or the query fails, stop the shortcut.
4. For cardio fitness, find the latest VO₂ max sample from the past 31 days. If present, make a second POST with the same token, that sample’s own date and `vo2_max` (Number, mL/kg/min). Omit `workout_minutes` from this request. If either sample type is unavailable on your phone, omit it. Repeated submissions for the same date update the supplied fields.
5. Run the shortcut manually once, approve the requested Health reads and network access, and check for the response **Saved** and the dated values in **Progress**. Open the next morning’s check-in to see available workout minutes. Then choose **Automation → Time of Day → Daily → Run Immediately** and select the tested shortcut. Health permissions, a locked phone and connectivity can affect unattended runs. Check the next dated row after the first scheduled run.
6. To disconnect, turn off the toggle and disable the phone automation. Existing summaries stay in your log. Only the token generated by this app plus the publishable key belong on the phone. Keep the database password and Streamlit password private.

Apple documents the available [time triggers](https://support.apple.com/guide/shortcuts/apd932ff833f/ios) and [JSON requests](https://support.apple.com/guide/shortcuts/apd58d46713f/ios).
