# Launch Project 5.14 in ChatGPT Plus

Use your regular ChatGPT Plus account on web or mobile. Everything runs in one dedicated conversation, so the daily plan, dated check-ins, and changes can be read together. This repository stores the instructions and never stores athlete check-ins.

1. Open **Scheduled** in ChatGPT and create a task named **Project 5.14 | Morning Coach**. Set it to run **every day at 6:00 a.m. America/Denver**. Check the timezone and next occurrence in the confirmation.
2. Copy the entire [task prompt](task-prompt.md) into the task. Replace `START_DATE` with today's date in Denver if you want to start now. Replace `WEEKLY_MILEAGE` and `WEEKLY_CLIMB_MINUTES` with recent typical weekly totals, or write `unknown`. Set `CHECKIN_URL` to your [browser check-in URL](check-in.md) or `NONE` to use text replies. If 6:00 a.m. has already passed, ask for Day 1 in the task's chat now; the next morning's scheduled run picks up on Day 2. If the manually requested Day 1 produces an email draft, decide whether to send it before confirming any Gmail action.
3. In **Settings → Notifications**, enable **Push** for scheduled tasks and allow ChatGPT notifications on your phone. If you want only the app prompt at 06:00, turn off ChatGPT task **Email** notifications. That setting controls task alerts and is separate from Gmail sending. From Day 2, open the notification. If you configured the browser form, open its link, tap your answers, then copy and paste the result into the task chat. Otherwise, reply with one line in the same chat. The prompt shows an example for the previous day's activity. For a climb, `A 48m 7 O N | P6 F` means completed, 48 minutes, effort 7/10, a little tired or sore this morning, no new discomfort, pump 6/10, and technique faded toward the end. On a rest day, `D G N` is enough. The plan appears after you respond. Choose `SKIP` for an easy fallback. Without a reply, no plan is created for that day.
4. For a **full email after the reply**, open **Settings → Apps → Gmail** and connect the wanted account. Check for a **Send email** action in the task's conversation when you answer the check-in. If it is offered, approve the sender and one recipient and set `EMAIL_MODE` in the prompt to `GMAIL`. An action that is available in the scheduled run may still be unavailable in the interactive reply. If Gmail only offers a draft or requires approval, follow the app's approval step or use `NOTIFICATION` mode (ChatGPT plan only). ChatGPT's built-in Email setting cannot send the completed plan on demand in response to your answer. The earlier GitHub Gmail authorization does not carry over to ChatGPT.
5. On Day 2, verify that the morning message contains the questions only and that your reply produces a dated plan in chat. Check Gmail separately if the send action was available. To fix your response, reply with a correction in the same conversation. At the end of Day 84, review the cycle summary and pause the task in **Scheduled**.

Use **pause training** in chat to hold prescriptions, and **resume training** for a conservative return. Pause the task itself in **Scheduled** to stop notifications. Keep check-ins in the dedicated conversation and avoid adding private clinical details or sharing the task.
