# Launch Project 5.14 in ChatGPT Plus

Use your regular ChatGPT Plus account on web or mobile. Everything runs in one dedicated conversation, so the daily plan, dated check-ins, and changes can be read together. This repository stores the instructions and never stores athlete check-ins.

1. Open **Scheduled** in ChatGPT and create a task named **Project 5.14 | Morning Coach**. Set it to run **every day at 6:00 a.m. America/Denver**. Check the timezone and next occurrence in the confirmation.
2. Copy the entire [task prompt](task-prompt.md) into the task. Replace `START_DATE` with today's date in Denver if you want to start now. Replace `WEEKLY_MILEAGE` and `WEEKLY_CLIMB_MINUTES` with recent typical weekly totals, or write `unknown`. If 6:00 a.m. has already passed, ask for Day 1 in the task's chat now; the next morning's scheduled run picks up on Day 2. If the manually requested Day 1 produces an email draft, decide whether to send it before confirming any Gmail action.
3. In **Settings → Notifications**, enable **Push** and **Email**. On mobile, allow notifications when prompted. Each morning, open the task notification to see the plan. From Day 2 onward, it also asks about the previous day. Reply there using the short check-in line. For an immediate change before training, say **adjust today**. After a reply, check the coach's dated record and correct it if needed.
4. To receive the **full email through Gmail**, open **Settings → Apps → Gmail** and connect the wanted Google account. In **Scheduled**, look for Gmail's **Send email** action in the task's available apps and actions. Only if it is offered for the scheduled task, add it, set the approved sender and one recipient, and verify action permissions. Set `EMAIL_MODE` in the prompt to `GMAIL` after that review. A Gmail connection may request per-action approval or omit the send action altogether. If so, use `NOTIFICATION` mode. ChatGPT's email notification does not guarantee the full email body. The earlier GitHub Gmail pilot authorization does not carry over to ChatGPT.
5. Open the task after the first scheduled run. Check the displayed date, next run time, and email behavior. On Day 2 confirm the message asks for Day 1 feedback and that a reply returns a dated adjustment. If the task can't see a previous reply, paste the latest **Record** from this chat and ask it to recalculate. At the end of Day 84, review the cycle summary and pause the task in **Scheduled**.

Use **pause training** in chat to hold prescriptions, and **resume training** for a conservative return. Pause the task itself in **Scheduled** to stop notifications. Keep check-ins in the dedicated conversation and avoid adding private clinical details or sharing the task.
